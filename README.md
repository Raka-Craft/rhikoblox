# Rhikoblox

Platform game mirip Roblox buatan **Raka** — main 52 game, kumpulkan Robux, dandani avatarmu!

## Fitur
- Login & daftar akun gaya Roblox (akun tersimpan di perangkat)
- Profil avatar di pojok kanan atas: edit display name (gratis), bio, statistik
- Ganti username berharga 1.000 Robux — display name gratis kapan saja
- Avatar bloky 5 kategori (rambut, wajah, baju, topi, aksesoris) — 30 item di Pasar
- Ekonomi Robux: bonus awal 100, bonus harian 100, hadiah Robux dari setiap game
- Sistem teman: tambah teman dari nama, ajak balapan langsung
- 52 game: XCraft (utuh, tersimpan otomatis), Balap Rhiko GP (lawan Bot / lawan Teman), dan 50 mini-game (Ular, Flappy, 2048, Blok Jatuh, Ranjau, Piano Tiles, Tembak Zombie, Labirin, Golf Mini, dan banyak lagi)

## Teknologi
Aplikasi Android WebView — seluruh platform berjalan dari `assets/index.html` + `games_a.js`, `games_b.js`, `games_c.js`. Game XCraft tertanam di `assets/xcraft.html`.
